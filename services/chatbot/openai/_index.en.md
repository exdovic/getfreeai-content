## 🚀 How to Use

### Prerequisites

- ✅ Registered OpenAI account (email or third-party account)
- ✅ Accessible network environment (Mainland China needs VPN)
- ❌ No credit card required

For detailed registration steps, please refer to: [OpenAI Registration Guide](/providers/openai#registration-and-account)

### Usage Steps

{{% steps %}}

##### Access and Login

1. Visit: [https://chat.openai.com](https://chat.openai.com)
2. Click "Log in" to sign in
3. Log in with your OpenAI account

##### Select Model

Select model at the top of the conversation interface:

| Model | Features | Usage Limits |
|-------|----------|--------------|
| **GPT-4o** | Strongest model, multimodal support | ~40-80 messages per 3 hours |
| **GPT-4o-mini** | Fast and lightweight, completely free | Unlimited |

##### Start Conversation

1. Type your question in the input box
2. Click send button or press Enter
3. Wait for ChatGPT's response
4. Continue multi-turn conversations

##### Use Advanced Features

**Upload Images:**
1. Click the 📎 icon on the left side of the input box
2. Select image file
3. Ask questions about the image

**Upload Files:**
1. Click the 📎 icon on the left side of the input box
2. Select document file (PDF, Word, TXT, etc.)
3. Let ChatGPT analyze or summarize

### Quota Description

**GPT-4o Limits:**
- Resets every 3 hours
- Specific count dynamically adjusted based on server load
- Automatically switches to GPT-4o-mini when limit reached
- Can continue using GPT-4o after waiting some time

**GPT-4o-mini:**
- Completely unlimited use
- Fast response
- Excellent quality
- Suitable for most daily tasks

### ⚠️ Important Limits

1. **Access Restriction:** Mainland China requires VPN to access
2. **Account Verification:** Needs valid phone number verification
3. **Advanced Features:** Web search, advanced data analysis require Plus subscription
4. **File Size:** Upload files have size limits (usually < 50MB)

## 💡 Usage Tips

### ✅ Best Practices

1. **Choose the Right Model**
   ```
   Complex tasks, image understanding → GPT-4o
   Daily conversations, quick queries → GPT-4o-mini
   ```

2. **Make Full Use of Image Features**
   - Upload charts for ChatGPT to analyze data
   - Upload design drafts for feedback
   - Upload problem photos for solutions
   - Use OCR to extract text from images

3. **Optimize Prompts**
   - Clearly and specifically describe requirements
   - Provide necessary background information
   - Specify output format and length
   - Use examples to illustrate expected results

4. **Manage Conversation History**
   - Save important conversations promptly
   - Regularly clean up unused conversations
   - Use meaningful conversation titles
   - Use search function to find quickly

5. **File Processing Tips**
   - Ensure correct file format before uploading
   - Clearly state what kind of analysis is needed
   - Can ask ChatGPT to summarize, translate, or rewrite
   - For large files, can process in sections

### ⚠️ Notes

1. **Quota Management**
   - GPT-4o has usage frequency limits
   - Allocate usage reasonably, prioritize important tasks
   - Can test prompts on GPT-4o-mini
   - Wait patiently for reset when limit reached

2. **Network Requirements**
   - Mainland China needs stable VPN tool
   - Unstable network may cause conversation interruption
   - Recommend using Chrome or Edge browser

3. **Privacy and Security**
   - Don't share sensitive personal information
   - Don't upload confidential documents
   - OpenAI may use conversations to improve models
   - Can disable data training use in settings

4. **Content Policy**
   - Follow OpenAI usage policies
   - Don't attempt to generate harmful content
   - Prohibited for illegal uses
   - Respect copyright and intellectual property

5. **Understanding Limitations**
   - ChatGPT knowledge cutoff is October 2023
   - Cannot access real-time information (free version no web search)
   - May produce inaccurate information (hallucinations)
   - Complex mathematical calculations may have errors

## 🔧 Common Questions

### 1. How to register for ChatGPT?

**Steps:**
1. Visit [https://chat.openai.com](https://chat.openai.com)
2. Click "Sign up"
3. Use Google account or email to register
4. Verify email and phone number
5. Complete registration

### 2. How to use from Mainland China?

**Solution:**
- Need VPN tool
- Ensure network stability
- Some regions may need special configuration
- Recommend using overseas phone number for registration

### 3. What to do when GPT-4o runs out?

**Solution:**
- Automatically switches to GPT-4o-mini
- Wait 3 hours for quota reset
- GPT-4o-mini quality is also excellent, can continue using
- Or consider upgrading to Plus ($20/month)

### 4. How to save conversations?

**Methods:**
- Conversations automatically save to history
- Can rename conversations for easy finding
- Can copy conversation content locally
- Plus users can export all conversations

### 5. Why are responses slow or interrupted?

**Common Causes:**
- High server load (peak hours)
- Unstable network connection
- Browser cache issues

**Solutions:**
- Wait some time and try again
- Check network connection
- Clear browser cache
- Try switching browsers

### 6. What's the difference between free and Plus?

| Feature | Free | Plus ($20/month) |

| Web Search | ❌ | ✅ |
