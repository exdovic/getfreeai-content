**功能：**

**示例：**
```
用户：用 Python 写一个函数，计算斐波那契数列的第 n 项

ChatGPT：
当然！以下是一个计算斐波那契数列第 n 项的 Python 函数：

def fibonacci(n):
    """
    计算斐波那契数列的第 n 项
    
    Args:
        n: 项数（从0开始）
    
    Returns:
        第 n 项的值
    """
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, a + b
        return b

# 使用示例
for i in range(10):
    print(f"F({i}) = {fibonacci(i)}")
```

### 1. 如何注册 ChatGPT？

- 确保网络稳定
- 部分地区可能需要特殊配置

### 3. GPT-4o 用完了怎么办？

**解决方法：**

- 等待 3 小时后配额重置
- GPT-4o-mini 质量也很好，可继续使用

### 4. 如何保存对话？

**方法：**
- 对话会自动保存到历史记录
- 可以给对话重命名便于查找
- 可以复制对话内容到本地
- Plus 用户可以导出所有对话

### 5. 为什么回复很慢或中断？

**常见原因：**
- 服务器负载高（高峰期）

**解决方法：**
- 等待一段时间后重试
- 检查网络连接
- 清除浏览器缓存
- 尝试切换浏览器
