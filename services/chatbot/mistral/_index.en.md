## ✅ Service Description

Le Chat is a free AI chatbot launched by Mistral AI in February 2024. Built on Mistral's advanced language models, particularly the multimodal Pixtral Large model, it can understand and generate text and images, with advanced features like web search and code execution.

### Key Features

- **🆓 Free to Use:** 10 conversations/day unregistered, 50+ after registration
- **🎨 Multimodal:** Powered by Pixtral Large, supports text and image understanding/generation
- **🌐 Real-time Info:** Built-in web search for latest information
- **💻 Code Execution:** Built-in code interpreter for running code
- **📱 Mobile Apps:** iOS and Android apps available (launched Feb 2025)
- **🇪🇺 European Servers:** Data stored in Europe, GDPR compliant

## 🚀 How to Use

### Prerequisites

**Free Use (No Registration):**
- Visit [https://chat.mistral.ai](https://chat.mistral.ai) directly
- 10 conversations per day

**Registered Use (Recommended):**
- Requires Mistral AI account
- See detailed steps: [Mistral AI Registration Guide](/providers/mistral#account-registration)

### Usage Steps

{{% steps %}}

##### Access Le Chat

Open [https://chat.mistral.ai](https://chat.mistral.ai), no login required to start (10/day limit).

##### Start Conversation

1. Type your question or request in the input box
2. Click send button or press Enter
3. Le Chat will generate a response

##### Use Advanced Features

**Upload Images:**
- Click the 📎 icon on the left of input box
- Select image to upload
- Le Chat will analyze and answer questions about it

**Generate Images:**
- Describe the image you want in conversation
- Example: "Generate an image of a sunset beach"
- Le Chat will use Flux Ultra to generate the image

**Web Search:**
- Le Chat automatically determines when to search
- You can explicitly request: "Search for latest..."
- Results include source links

**Code Execution:**
- Ask Le Chat to write and run code
- Example: "Draw a sine function graph in Python and run it"
- Le Chat will execute code and show results

## 🔧 Common Questions

**Q: Is Le Chat completely free?**  
A: Le Chat offers a free version with reference quotas of ~10 daily conversations unregistered, ~50+ after registration (actual quotas subject to official site, may change). For unlimited use and advanced features, subscribe to Pro ($14.99/month).

**Q: How to increase free quota?**  
A: Register a Mistral AI account to increase from 10 to 50+ daily conversations. No payment required, just registration.

**Q: What languages does Le Chat support?**  
A: Le Chat supports multiple languages including English, French, Chinese, Spanish, etc. As a European company, it has especially good support for European languages.

**Q: Who owns generated image copyrights?**  
A: According to Mistral AI's terms of service, user-generated content belongs to users, but Mistral AI reserves rights for service improvement. Check latest terms before commercial use.

**Q: Is data used for model training?**  
A: Mistral AI may use conversation data to improve models. If concerned about privacy, avoid sharing sensitive information. Pro users may have more privacy protection options.
