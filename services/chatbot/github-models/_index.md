## 📋 服务概览

**服务名称：** GitHub Models Playground  
**所属提供者：** [GitHub Models](/providers/github-models)  
**访问地址：** [https://github.com/marketplace/models](https://github.com/marketplace/models)（选择模型后进入 Playground）

## ✅ 服务说明

GitHub Models Playground 是 GitHub 提供的网页端 AI 对话服务，允许用户直接在浏览器中与多种主流 AI 模型进行交互对话，无需任何配置或 API 密钥。

### 主要特点

- **🎯 开箱即用** - 登录 GitHub 即可使用，无需额外配置
- **🆓 完全免费** - 所有功能完全免费，无隐藏费用
- **🤖 多模型支持** - 支持 GPT-4o、Llama、Phi、DeepSeek 等 10+ 模型
- **🔄 自由切换** - 可随时切换不同模型进行对比测试
- **💬 即时对话** - 实时响应，流畅的对话体验
- **🔍 模型对比** - 方便对比不同模型的性能和特点

### 核心功能

- ✅ **文本对话** - 支持多轮对话，保持上下文

## 🔢 使用限制

### 免费配额

| 限制项 | 配额 | 说明 |
|--------|------|------|
| **使用次数** | 因模型而异 | 每个模型有独立的速率限制 |
| **单次对话长度** | 因模型而异 | 取决于模型的上下文窗口 |
| **上下文记忆** | 支持 | 自动保持对话上下文 |
| **文件上传** | ❌ 不支持 | 仅支持文本输入 |
| **联网搜索** | ❌ 不支持 | 基于模型训练数据 |
| **需要信用卡** | ❌ 不需要 | 完全免费 |

### ⚠️ 重要限制

1. **速率限制：** 每个模型有不同的速率限制，例如 GPT-4o 每天限制 50 次请求，达到限制后需要等待配额重置。
2. **上下文限制：** 对话上下文长度取决于所选模型，超出后会自动截断。
3. **功能限制：** 目前不支持文件上传、图像输入、联网搜索等高级功能。
4. **账户要求：** 必须拥有有效的 GitHub 账户才能使用。

## 🚀 如何使用

### 前提条件

**注册 GitHub 账户：**
- 如果您还没有 GitHub 账户，请先 [注册账户](/providers/github-models#注册账户)
- 确保您的 GitHub 账户已验证邮箱

### 使用步骤

{{% steps %}}

##### 访问 GitHub Models

1. 打开 [https://github.com/marketplace/models](https://github.com/marketplace/models)
2. 使用您的 GitHub 账户登录
3. 浏览可用的 AI 模型列表

##### 选择 AI 模型

1. 点击您感兴趣的模型（例如 GPT-4o, Llama 3.1, Phi-3 等）
2. 查看模型的详细信息和速率限制
3. 点击"Try in Playground"按钮

##### 开始对话

1. 在 Playground 界面的输入框中输入您的问题或提示词
2. 点击发送按钮或按 Enter 键
3. 等待模型生成回复
4. 继续对话或调整参数

##### 切换模型（可选）

1. 点击左上角的模型选择器
2. 选择其他模型进行对比
3. 同一个对话可以切换不同模型查看效果

##### 调整参数（可选）

1. 在右侧面板中可以调整：
   - **Temperature（温度）：** 控制输出的随机性（0-1）
   - **Max Tokens：** 控制最大输出长度
   - **Top P：** 控制输出的多样性
2. 调整后重新发送问题查看效果

{{% /steps %}}

## 💡 实用技巧

### ✅ 推荐做法

1. **选择合适的模型：**
   - **复杂任务：** 使用 GPT-4o 或 Llama-3.1-405B
   - **日常对话：** 使用 GPT-4o-mini 或 Llama-3.1-8B
   - **中文任务：** 使用 DeepSeek-R1
   - **知识检索：** 使用 Cohere Command-R+

2. **优化提示词：**
   - 提供清晰的上下文和背景信息
   - 使用具体的示例说明期望输出
   - 分步骤描述复杂任务
   - 明确指定输出格式

3. **合理使用速率限制：**
   - 提前了解每个模型的限制
   - 达到限制后切换到其他模型
   - 避免无意义的重复请求
   - 合并相似的问题一次性提问

### 🎯 最佳实践

**高效提问：**
- ✅ 问题要具体明确，避免模糊不清
- ✅ 提供必要的背景信息和上下文
- ✅ 使用分步骤的方式处理复杂任务
- ❌ 避免过于宽泛的问题
- ❌ 不要提供过多无关信息

**充分利用免费配额：**
- 使用 Playground 测试和优化提示词
- 确定最佳模型后再使用 API
- 对比不同模型的效果
- 学习和研究模型特点

**模型对比：**
```
同一个问题可以尝试不同模型：
1. 用 GPT-4o 获取高质量回答
2. 用 Llama-3.1-70B 对比开源模型表现
3. 用 DeepSeek-R1 查看中文优化效果
4. 选择最适合您需求的模型
```

### ⚠️ 注意事项

1. **速率限制：** 达到限制后需要等待配额重置，建议合理分配使用。配额为参考值，请以 [官方页面](https://github.com/marketplace/models) 为准。
2. **上下文管理：** 长对话可能超出模型上下文限制，及时开始新对话。
3. **数据隐私：** 请勿输入敏感信息（密码、密钥、个人隐私等）。
4. **网络要求：** 部分地区访问 GitHub 可能需要特殊网络环境。

## 🔧 常见问题

**Q: 如何访问 GitHub Models Playground？**  
A: 登录 GitHub 账户后，访问 [https://github.com/marketplace/models](https://github.com/marketplace/models)，选择模型后点击"Try in Playground"即可。

**Q: 为什么达到速率限制？**  
A: 每个模型有独立的速率限制，例如 GPT-4o 每天限制 50 次请求。达到限制后可以：1) 等待配额重置（通常为每日 UTC 0:00），或 2) 切换到其他模型继续使用。

**Q: 可以保存对话历史吗？**  
A: Playground 会自动保存对话历史，您可以在左侧栏查看和访问历史对话。

**Q: 支持中文吗？**  
A: 所有模型都支持中文，但 DeepSeek-R1 模型对中文有特别优化，推荐用于中文任务。

**Q: 如何选择合适的模型？**  
A: 
- 复杂推理任务：GPT-4o 或 Llama-3.1-405B
- 日常对话：GPT-4o-mini 或 Llama-3.1-8B
- 中文任务：DeepSeek-R1
- 知识检索：Cohere Command-R+
- 多语言：Mistral-Large

**Q: Playground 和 API 有什么区别？**  
A: Playground 是网页对话界面，适合测试和学习；API 是编程接口，适合集成到应用中。建议先用 Playground 测试，确定模型后再使用 API。

**Q: 需要付费吗？**  
A: GitHub Models Playground 完全免费，无需信用卡，但有速率限制。

**Q: 为什么有些模型无法使用？**  
A: 可能的原因：1) 达到该模型的速率限制，2) 模型暂时不可用，3) 您的账户未通过验证。请检查模型详情页的状态说明。
