### Registration Steps

{{% steps %}}

##### Register Account

1. Visit [https://chat.openai.com](https://chat.openai.com)
2. Click "Sign up" to register or "Log in" to sign in
3. Choose registration method:
   - Google Account (recommended)
   - Microsoft Account
   - Apple Account
   - Email Registration

##### Verify Email

1. If using email registration, check your inbox for verification email
2. Click the verification link in the email
3. Complete email verification

##### Verify Phone Number

1. Enter phone number (supports China +86)
2. Receive and enter verification code
3. Complete phone verification

##### Start Using

1. After verification, you can use ChatGPT
2. For API access, visit [https://platform.openai.com](https://platform.openai.com)
3. Create API key in the console

## ⚠️ Usage Notes

### Access Restrictions

- **Regional Restrictions:** Mainland China cannot access directly, requires special network environment
- **Phone Verification:** Some virtual numbers may not receive verification codes
- **Account Security:** Recommend using strong passwords, enable two-factor authentication

### Free Version Limitations

**ChatGPT Free Version:**
- GPT-4o has usage frequency limits (~40-80 messages per 3 hours)
- Automatically switches to GPT-4o-mini when limit reached
- May need to queue during peak hours
- Web search feature requires Plus subscription

**API Free Credits:**
- $18 credits expire after 3 months
- Free tier has rate limits (3 RPM)
- Need to bind payment method after credits used

### Content Policy

- Follow OpenAI usage policies
- Prohibited from generating harmful content
- Prohibited from illegal uses
- Respect copyright and privacy

### Quota Management

**Chatbot:**
- GPT-4o limits dynamically adjusted, no fixed number
- Recommend reasonable use, avoid frequent refreshing
- Can use GPT-4o-mini as alternative

**API:**
- Check remaining credits in console
- Set usage limits to avoid overspending
- Monitor API call status
