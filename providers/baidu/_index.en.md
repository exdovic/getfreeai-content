## 📋 Product Overview

Baidu is China's leading internet company, and its ERNIE Bot (Wenxin Yiyan) is a representative work of Chinese large language models. Starting from April 1, 2025, Baidu announced that ERNIE Bot will be fully free and open to all users.

**Core Features:**
- 🎉 **Fully Free** - Chatbot fully free from April 1, 2025
- 🆕 **Latest Models** - ERNIE 4.5 multimodal, ERNIE X1 reasoning
- 🇨🇳 **Chinese Optimized** - Top-tier Chinese language performance
- 🎨 **Multimodal Support** - Text, image, audio, video
- ⚡ **Permanently Free API** - ERNIE-3.5-8K, ERNIE-Speed-8K
- 🚀 **Fast Domestic Access** - Servers in China, fast response
- 🔒 **Compliant for Commercial Use** - Domestic compliance, safe for business

**Recommendation:** ⭐⭐⭐⭐⭐ (Top choice for Chinese, leading domestic AI!)

## 🔐 Registration and Account

### Registration Requirements

**Chatbot (ERNIE Bot):**

| Requirement | Required | Description |
|------------|----------|-------------|
| Baidu Account | ✅ Required | Register with phone or email |
| Phone/Email Verification | ✅ Required | Based on registration method |
| Real-name Verification | ❌ Not Required | Not needed for Chatbot |
| Credit Card | ❌ Not Required | Completely free |

**API Service (Qianfan Platform):**

| Requirement | Required | Description |
|------------|----------|-------------|
| Baidu Cloud Account | ✅ Required | Register for Baidu Cloud |
| Real-name Verification | ✅ Required | Required for API use |
| Credit Card | ❌ Not Required | Supports Alipay/WeChat |

### Registration Steps

#### Chatbot Registration (Simplest)

{{% steps %}}

##### Visit ERNIE Bot

Open your browser and visit [https://yiyan.baidu.com](https://yiyan.baidu.com).

##### Login with Baidu Account

Login with your Baidu account (register if you don't have one). Supports:
- Phone number registration
- Email registration
- WeChat/QQ quick login

##### Start Using

After login, you can use all ERNIE Bot features for free.

{{% /steps %}}

#### API Registration (Requires Verification)

{{% steps %}}

##### Visit Qianfan Platform

Open [Baidu Cloud Qianfan Platform](https://qianfan.cloud.baidu.com).

##### Register Account

Register a Baidu Cloud account (can use existing Baidu account).

##### Complete Real-name Verification

1. Go to [Real-name Verification Page](https://console.bce.baidu.com/idc/#/personal/verify)
2. Upload ID (personal) or business license (enterprise)
3. Wait for review (about 10 minutes)
4. ⚠️ **Important:** Real-name verification is required for API use

##### Create Application

1. Create an application in Qianfan console
2. Get API Key and Secret Key
3. Start using free API

{{% /steps %}}
