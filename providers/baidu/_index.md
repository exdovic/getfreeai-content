### 注册步骤

#### Chatbot 注册（最简单）

{{% steps %}}

##### 访问文心一言

打开浏览器，访问 [https://yiyan.baidu.com](https://yiyan.baidu.com)。

##### 使用百度账号登录

使用百度账号登录（如无账号需注册）。支持：
- 手机号注册
- 邮箱注册
- 微信/QQ 快捷登录

##### 开始使用

登录后即可免费使用文心一言所有功能。

{{% /steps %}}

#### API 注册（需实名）

{{% steps %}}

##### 访问千帆平台

打开 [百度智能云千帆平台](https://qianfan.cloud.baidu.com)。

##### 注册账户

注册百度智能云账户（可使用已有的百度账号）。

##### 完成实名认证

1. 进入 [实名认证页面](https://console.bce.baidu.com/idc/#/personal/verify)
2. 上传身份证（个人）或营业执照（企业）
3. 等待审核（约10分钟）
4. ⚠️ **重要：** 实名认证是使用 API 的必要条件

##### 创建应用

1. 在千帆控制台创建应用
2. 获取 API Key 和 Secret Key
3. 开始使用免费 API

{{% /steps %}}

## ⚠️ 使用注意事项

### 实名认证

- **Chatbot：** 无需实名认证
- **API：** 必须完成实名认证
- **审核时间：** 约10分钟
- **认证入口：** [点击这里](https://console.bce.baidu.com/idc/#/personal/verify)

### 内容审核

- 遵守中国法律法规
- 敏感内容会被拒绝
- 专注合法合规使用

### QPS 限制

- 免费模型 QPS 为 50
- 超出限制会排队等待
- 可通过付费提高 QPS

### 地区支持

- 主要服务中国大陆用户
- 海外访问可能较慢
- 建议国内用户使用
