```python
用户：请帮我分析这段代码的时间复杂度并优化

Claude：
这段代码的时间复杂度分析如下：

1. 原始代码：O(n²)
   - 外层循环：O(n)
   - 内层循环：O(n)
   - 总复杂度：O(n²)

2. 优化后：O(n)
   - 使用哈希表存储
   - 单次遍历
   - 空间复杂度：O(n)

优化代码：
def optimized_solution(arr, target):
    seen = {}
    for i, num in enumerate(arr):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return None
```
