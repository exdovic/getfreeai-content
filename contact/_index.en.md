### 🐙 GitHub

Our open-source project is hosted on GitHub - the best way to participate!

#### GitHub Repository
**🔗 [github.com/exdovic/getfreeai-content](https://github.com/exdovic/getfreeai-content)**

#### Contact Us via GitHub

1. **Submit an Issue** (Recommended)
   - 🐛 [Report a Bug](https://github.com/exdovic/getfreeai-content/issues/new?labels=bug)
   - 💡 [Feature Request](https://github.com/exdovic/getfreeai-content/issues/new?labels=enhancement)
   - 📖 [Documentation Issue](https://github.com/exdovic/getfreeai-content/issues/new?labels=documentation)
   - ❓ [Ask a Question](https://github.com/exdovic/getfreeai-content/issues/new?labels=question)

2. **Submit a Pull Request**
   - Contribute new AI service documentation
   - Update outdated or inaccurate information
   - Improve existing documentation
   - Fix errors

3. **Participate in Discussions**
   - Review and reply to existing Issues
   - Provide feedback on Pull Requests
   - Participate in community discussions

**Why GitHub?**
- ✅ Public and transparent, visible to the community
- ✅ Issues can be tracked and resolved
- ✅ Easy collaboration and contribution
- ✅ Usually faster responses

## 💬 Feedback Types

### 🐛 Report Issues

If you find any of the following problems, please let us know:

- **Incorrect Information**: Inaccurate or outdated information in documentation
- **Broken Links**: Links that cannot be accessed
- **Technical Issues**: Website display or functionality problems
- **Typos**: Text errors or formatting issues

**Best Channel**: [GitHub Issues](https://github.com/exdovic/getfreeai-content/issues)

## 🌟 Community Guidelines

When communicating with us, please follow these guidelines:

### ✅ We Expect

- **Respect Others**: Polite, friendly communication
- **Constructive Feedback**: Provide specific, actionable suggestions
- **Patient Understanding**: We are a volunteer-maintained project
- **Clear Expression**: Provide sufficient detail when describing issues

### ❌ Please Avoid

- Inappropriate speech or harassment
- Spam or advertisements
- Repeatedly submitting the same issue
- Irrelevant discussions
